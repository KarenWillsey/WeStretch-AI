# Marketing Skills — Summary

49 marketing skills installed from [coreyhaines31/marketingskills](https://github.com/coreyhaines31/marketingskills). Each lives at `.agents/skills/<name>/` and is linked into `.claude/skills/<name>` via a Windows directory junction (see root `CLAUDE.md`, "Third-party skill packages"). Plus a shared `tools/` directory (integration guides + CLI helpers) that many of these skills reference internally.

## Conversion & pages

- **cro** — Conversion rate optimization for landing/pricing/feature pages and forms.
- **copywriting** — Write or rewrite persuasive marketing copy for any page (hero, CTA, value prop).
- **copy-editing** — Edit, tighten, or refresh existing copy rather than writing from scratch.
- **signup** — Optimize signup/registration/trial activation flows to cut drop-off.
- **onboarding** — Improve post-signup activation, first-run experience, time-to-value.
- **paywalls** — Design in-app upgrade screens, upsell modals, and feature gates.
- **popups** — Build/optimize popups, modals, exit-intent overlays, and banners.
- **pricing** — Pricing tiers, packaging, freemium/trial structure, pricing-page audits.
- **offers** — Construct the offer itself: bonuses, guarantees, scarcity, value stacking.
- **site-architecture** — Plan sitemap, navigation, URL structure, and internal linking.

- **content-strategy** — Decide what content to create; topic/editorial planning.
- **seo-audit** — Diagnose technical/on-page SEO issues and ranking drops.

- **directory-submissions** — Submit product to startup/SaaS/AI directories for backlinks and discovery.
