- `https://drive.google.com/drive/folders/1aLVKekBrMFbkzTPyPDOGrESWUE_tWEEh` — Components; Ada composites and mixed scenes.
- `https://drive.google.com/drive/folders/1TmMxwBvAdXgJntv1IXSqE6ddaTKJCQNV` — Single Building Blocks; Ada-only poses, alternate clothing, Bruce and mixed scenes.

Place **female Ada originals** from these folders in `../assets/ada-references/`, retaining filenames. Include clean Ada images across front, profile, back, face, and multiple poses. Exclude Bruce-only and background-only files. A mixed Ada/Bruce or phone composite may be kept as secondary context if it shows a useful Ada angle, but label its role in the prompt. The canonical bundled assets already cover a front view, rear view, and two close-ups.

Inspect each newly added file for readability and corruption before using it. Prefer the original full-resolution file to a screenshot or flattened composite. Do not let a newer generated image supersede the original identity anchors. If originals conflict on facial features or proportions, use `Ada_1.png` and `Ada_front.png` until Karen selects another canonical set.

The original Google Drive downloads were unavailable in the browser used to assemble this package. The bundled canonical images came from the existing `Ada-Stretching-Phone-Image` skill assets available in the workspace; this catalog does not claim every file from both Drive folders is included.
