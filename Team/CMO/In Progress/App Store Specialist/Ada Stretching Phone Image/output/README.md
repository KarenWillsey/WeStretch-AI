# Output

Flat folder: no subfolders. Every delivered image (both required sizes, see `SKILL.md` § Output sizes) is saved directly here.

Filename pattern: `<pose-slug>-<mode>-<size-label>.png`, e.g.:
- `forward-fold-inside-phone-iphone-6.9.png`
- `forward-fold-inside-phone-ipad-13.png`
- `runners-lunge-trompe-loeil-iphone-6.9.png`
- `runners-lunge-trompe-loeil-ipad-13.png`
