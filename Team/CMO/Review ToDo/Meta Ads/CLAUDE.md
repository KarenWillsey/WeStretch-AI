# Meta Ads (Women 50-65, 5 Angles, 25 Concepts)

Scope: this project is one deliverable, a batch of 25 static-ad concepts for
Meta (Facebook/Instagram) targeting women 50-65, WeStretch's primary
acquisition audience per `Team/CMO/skills/westretch-direct-response-marketing/references/westretch-context.md`.

Built with the `westretch-direct-response-marketing` skill (Mode 3: Ad
creation), organized by AIDA and message awareness, in
`Meta Ads - Women 50-65 - 25 Concepts.md`.

## What this is not

This is concepts and copy only: hooks, headlines, primary text, visual
direction, and hypotheses to test. No images have been generated and no
campaigns have been built in Meta Ads Manager. Producing the actual images
is a separate follow-on step (see the deliverable's "Next steps" section).
