# Yard Design

Three corrected temporary landscape concepts for the east and west parcels
beside the house.

## Files

- `Design Concepts.md`: comparison, design rules and next-step checks.
- `Drafts/Round 02/01-Continuous-Frame.png`: light continuous framing.
- `Drafts/Round 02/02-Rolling-Frame.png`: stronger rolling perimeter hills.
- `Drafts/Round 02/03-Tree-Anchor-Frame.png`: minimal framing with corner trees.
- `Drafts/Round 02/03-Curved-Mound-Frame-Revised.png`: revised Version 3 using
  the organic mound architecture marked in Karen's yellow reference.
- `Drafts/Round 03/01-Corner-Mound-Study.png`: Step 1 land-form study showing
  four separate, dimensional corner mounds with no planting decisions.
- `Robot Mower and Mound Research.md`: researched mound language, mower
  installation strategy and tree-base guidance.
- `References/Plant Base Examples/plant-base-examples-contact-sheet.jpg`: five
  visual references for planted tree and shrub bases.
- `References/current-yard-contact-sheet.jpg`: stitched overview of the current
  yard photographs.
- `References/parcel-map.png`: supplied aerial parcel map.

The drawings are concept plans, not measured construction plans.

`Drafts/Round 01/` and the original Round 02 Version 3 are superseded and
retained only as working history.
