Persistent memory for the CTO role only — facts, feedback, and context that
apply across CTO's work but aren't specific to a single project (those live in
that project's own `Memory.md` under `Ideas/`, `In Progress/`, or `Ready/`).
Nothing role-specific has come up yet; add entries here as CTO work happens,
following the same style as the root `Memory.md` (fact/rule, then **Why:**
and **How to apply:** lines).
