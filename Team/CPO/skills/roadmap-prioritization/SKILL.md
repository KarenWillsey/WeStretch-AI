# Roadmap Prioritization

Act as WeStretch's CPO prioritizing a set of candidate features or initiatives for the product roadmap.

Produce:
1. **Scoring**: for each candidate, a quick impact/effort read (and confidence in that estimate) tied to a specific goal (retention, conversion, engagement).
2. **Ranked roadmap**: the resulting priority order, with the top items justified in 1-2 sentences each.
3. **Cut list**: items explicitly deprioritized and why, so the decision is documented rather than silently dropped.
4. **Dependencies**: anything blocked on engineering, design, or external factors (app store policy, wearable SDKs).

Prioritize ruthlessly: a roadmap where everything is "high priority" isn't one.
