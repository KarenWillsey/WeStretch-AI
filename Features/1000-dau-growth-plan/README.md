# Initiative: Reach 1,000 DAU

## Goal

Grow WeStretch from its current daily-active-user (DAU) base to **1,000 DAU within 3 months**, using the resourcing constraints stated for this planning pass.

## Stated inputs (from CEO, this planning pass — not derived from repo data)

- **Current DAU**: 1–200 (range given, not an exact figure — treat "~200" as the working assumption since it's the more tractable end, but this must be confirmed before the plan below is trusted).
- **Timeframe**: 3 months.
- **Resourcing**: bootstrap — no dedicated marketing budget, small team covering multiple roles.

This repo has no analytics, financial, org, or product-usage data on file. Every role doc below is written against the three inputs above; anywhere a doc would otherwise need real figures (actual DAU, actual funnel, actual team size, actual pricing), it says so explicitly instead of inventing a number. That gap — no confirmed source of truth for DAU or the funnel beneath it — is the single biggest risk to this plan and is called out again in [synthesis.md](synthesis.md).

## Scope for this planning pass

One planning document per relevant executive function, each produced using that role's skill(s) from `../../<ROLE>/skills/`. Read [synthesis.md](synthesis.md) first for the cross-functional plan, agreements, and the disagreement that was deliberately preserved rather than papered over; the individual role docs contain the full reasoning.
